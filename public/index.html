How should we run the model?

MiniChat is free and works without any API key — the model just has to run somewhere. Pick where. You can change this any time in Settings.

Honest note: a frontier model like Claude or GPT-5 can't be run for free — it needs a paid API or a server farm. The free routes above are genuinely good, just a tier or two below.
